# RDX05 — Methods

1. Inspection completion and public classification are different clocks.
2. Use final NAI/VAI/OAI only when publicly posted; no retroactive visibility.
3. Form 483 public availability is selected/incomplete; absence is not negative evidence.
4. Preserve project-area-specific classifications.
5. Use FEI as durable facility identity; company names/ownership change.
6. Warning-letter issue date and web publication time are separate where observable.
7. OAI is regulatory recommendation/state, not automatic shutdown.
8. Distinguish domestic enforcement from foreign import-control pathways.
9. Import Alert listing and removal are separate public events.
10. Map exact facility/product/application exposure; do not assign entire issuer.
11. Separate API, biologic, sterile injectable, device and finished-dose production economics.
12. Alternate site counts only if regulatorily approved/qualified for the relevant product.
13. Application withholding is exposure only when product/application actually relies on the facility.
14. Deduplicate one quality event across 483, OAI, warning letter, recall and shortage.
15. Archive every inspection dashboard/import-alert vintage used.
16. Respect FDA source caveats: classification database is not comprehensive.
17. Control for known recalls/shortages already public before enforcement event.
18. Use warning letters as enforcement facts, not inference that every cited risk caused production loss.
19. Validate recovery with reinspection/classification/import status and physical supply.
20. Before financial alpha require OOS prediction of enforcement, import constraint, approval delay, production suspension, recall, shortage or recovery.
