# RDX05 — Sources

## D01 FDA Inspection Classification Database
https://www.fda.gov/inspections-compliance-enforcement-and-criminal-investigations/inspection-classification-database
Final NAI/VAI/OAI classifications. FDA says the dashboard is updated weekly and is not comprehensive.

## D02 Inspection Classification Semantics
https://www.fda.gov/inspections-compliance-enforcement-and-criminal-investigations/inspection-basics/inspection-classifications
NAI=no action; VAI=objectionable conditions but voluntary correction; OAI=official/admin action recommended.

## D03 Human Drug Inspection Timing
https://www.fda.gov/drugs/guidance-compliance-regulatory-information/pharmaceutical-inspections-and-compliance
FDA says it strives to complete human-drug CGMP classifications within 90 days of inspection end; OAI can affect approval of applications/supplements.

## D04 Form FDA 483 / Inspection Observations
https://www.fda.gov/inspections-compliance-enforcement-and-criminal-investigations/inspection-references/inspection-observations
483s record objectionable conditions observed by investigators.

## D05 OII FOIA Electronic Reading Room
https://www.fda.gov/about-fda/office-inspections-and-investigations/oii-foia-electronic-reading-room
Not all 483s/EIRs are posted; proactive disclosure/request selection creates coverage bias.

## D06 FDA Warning Letters
https://www.fda.gov/inspections-compliance-enforcement-and-criminal-investigations/compliance-actions-and-activities/warning-letters
Public letters provide inspection dates, findings, requested corrective action and possible approval/import consequences.

## D07 FDA Data Dashboard
https://www.fda.gov/about-fda/performance-data/fda-data-dashboard
Combines finalized inspections/compliance actions; source data can change and have caveats.

## D08 FDA Import Program / Import Alerts
https://www.fda.gov/industry/import-program
https://www.accessdata.fda.gov/cms_ia/
Import Alerts can impose Detention Without Physical Examination on specified products/firms.

## D09 FDA Drug Shortages
Existing repo shortage sources should be used to validate whether quality action became supply disruption.

## D10 Facility/Product Mapping
Use FDA FEI, registration/listing/application data and issuer filings. Do not infer facility exposure from company name alone.
