# Composite System Concepts

These are multi-source inventions intended to create orthogonal state variables. They are not implementation instructions.

## C01 — Market Causal Weather Map
Inputs:
options hedge pressure, futures liquidity capacity, Treasury flow, rates, volatility, macro expectations.

Output:
a directed state graph describing where pressure originates and how it can propagate.

Example:
Treasury auction shock -> 10Y yield -> NQ duration pressure -> dealer option hedge demand -> futures liquidity failure.

Goal:
Replace isolated signals with causal pathways.

## C02 — Physical Economy Nervous System
Fuse:
ports + river/locks + rail + grid + aviation + internet + nighttime lights + USDA physical market data.

Represent:
nodes = physical systems/geographies
edges = actual logistics/economic dependencies
state = surprise relative to expected flow

Output:
real-economy nowcast independent of conventional monthly releases.

## C03 — Semiconductor Reality Index
Fuse:
Korea semiconductor exports + Taiwan electronics exports/orders + fab-region nighttime lights + power demand + air freight + semiconductor corporate filings.

Targets:
semiconductor basket first, then NQ.

Critical:
test whether the index predicts earnings/revenue surprises before testing futures returns.

## C04 — Fiscal-Monetary Liquidity Tensor
Fuse:
Daily Treasury Statement + TGA + Treasury settlements + ON RRP + reserves + repo + money-market assets + primary dealer financing.

Output axes:
- reserve injection/drain
- collateral abundance/scarcity
- dealer capacity
- cash reservoir
- maturity supply

Goal:
separate "liquidity" into measurable mechanisms rather than a single narrative variable.

## C05 — Option Hedge Shock Absorber
Fuse:
gamma/vanna/charm estimated hedge demand + ES/NQ book replenishment + recent realized impact + volatility regime.

Output:
expected mechanical impact per unit of underlying move.

This may explain convex intraday acceleration without pretending dealer positioning is deterministic.

## C06 — Information Diffusion Graph
Fuse:
EDGAR filings + supplier/customer graph + index membership + options/futures exposure + market reaction.

Question:
Which public filing has information content for a different security that has not repriced yet?

Require:
lagged reaction only; no use of contemporaneous target return to define propagation.

## C07 — Disaster Reality Gap
Fuse:
NWS warning severity + FEMA declaration + Cloudflare outage + Black Marble light loss + grid load loss + air/rail/port disruption.

Feature:
RealityGap = measured physical disruption - headline/implied disruption.

Hypothesis:
markets over/underreact when narrative severity differs from observed physical impact.

## C08 — Global Cargo Pressure Wave
Fuse:
Port of LA forward manifests + global satellite port stack + AIS/vessel arrivals + rail/intermodal + retail inventory.

Output:
expected arrival wave, inventory replenishment pressure and congestion risk.

Research targets:
retail, transports, inflation components, industrial sectors before broad index.

## C09 — River-to-Futures Transmission Model
Fuse:
USGS water + USACE locks + barge constraints + USDA basis/exports + futures curve.

Goal:
estimate how physical transportation bottlenecks transmit to regional basis and then futures.

Strong falsification:
if cash/basis adjusts first and futures do not, classify as basis-only edge rather than forcing a futures strategy.

## C10 — Latent Dealer Constraint State
Fuse:
primary dealer positions + financing + fails + sponsored repo + Treasury supply + volatility + TRACE customer/dealer activity.

Output:
dealer balance-sheet scarcity probability.

Use:
conditioning variable for auction/flow signals.

## C11 — Forecast Revision Alpha
For every forward-looking source, store vintages:
port arrivals, grid load, weather, economic expectations, prediction markets.

Features:
level, first derivative, second derivative, disagreement, revision half-life.

Hypothesis:
revision dynamics can be more informative than consensus level.

## C12 — Edge Genome
Represent each candidate by:
source family, mechanism, horizon, target, dependence on liquidity, regime sensitivity, expected capacity, turnover, data cost, crowding vulnerability.

Use:
diversify research portfolio by mechanism, not by model name.

## C13 — Alpha Orthogonality Graph
Nodes:
candidate edges.
Edges:
residual prediction correlation after neutralizing common market factors.

Goal:
avoid "20 models" that are all momentum with different cosmetics.

## C14 — Edge Mortality Model
Predict candidate failure probability from:
recent degradation, calibration drift, source revisions, crowding, structural rule changes, volatility shift, execution slippage.

Output:
survival probability and expected remaining half-life.

## C15 — Macro Expectation Surface
Fuse:
Kalshi distributional probabilities + rates/futures + surveys + options.

Do not use only expected value.
Use:
skew, entropy, multimodality, tail-probability shifts and disagreement across instruments.

Target:
reaction to CPI/jobs/Fed releases rather than raw directional prediction.

## C16 — Surprise-of-Surprise Engine
Build expected market reaction from comparable historical states.
Then trade/research the residual:
actual reaction - state-conditioned expected reaction.

Example:
CPI surprise was hot, but rates response is far weaker than expected given gamma/liquidity/dealer state. That divergence may be more informative than the CPI surprise itself.

## C17 — Physical-to-Financial Lead-Lag Search
First prove:
physical sensor -> delayed official KPI.

Then prove:
physical sensor -> market expectation change.

Only then test:
physical sensor -> tradable return.

This hierarchy prevents "alternative data theater."

## C18 — Market Absorption Quotient
General form:
MAQ = exogenous_pressure / adaptive_liquidity

Pressure sources:
auction, options hedging, ETF close flow, macro shock, liquidation.

Liquidity:
visible depth + refill speed + cross-venue substitutes + dealer capacity.

Universal research question:
when does pressure exceed absorption?

## C19 — Multi-Sensor Facility State
For physical facilities:
factory/refinery/data center/port/mine.

Fuse:
night lights + grid + NO2 + fire/weather + internet + transport.

Output:
operating / impaired / shutdown / restarting, with confidence.

## C20 — Truth Ladder
Every signal is tagged by distance from reality:
L0 price-derived
L1 order/transaction flow
L2 contractual/institutional flow
L3 operational telemetry
L4 physical-world sensor
L5 official realized outcome

Research preference:
seek edges where a higher truth layer moves before a lower layer has fully repriced.
