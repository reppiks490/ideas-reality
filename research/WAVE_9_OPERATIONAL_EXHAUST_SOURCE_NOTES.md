# Wave 9O — Primary Source Notes

Namespace: W9O

## W9O-D01 — FERC / Interstate Pipeline Informational Postings
https://www.ecfr.gov/current/title-18/chapter-I/subchapter-I/part-284/subpart-A/section-284.12

Interstate pipeline public electronic postings are standardized under FERC/NAESB requirements. Pipelines must post critical operational notices publicly.

## W9O-D02 — 2026 Gas-Electric Coordination Standards
FERC 2026 final rule incorporating updated NAESB WGQ standards requires a new Gas Electric Coordination posting category with an effective tariff date in 2027. Treat as FUTURE until compliant data are actually observed.

## W9O-D03 — ENTSOG Transparency Platform
https://transparency.entsog.eu/api/v1/

Public REST API supports JSON/XML/CSV/XLSX and operational fields including nominations, renominations, allocations, physical flows, capacities and interruptions.

## W9O-D04 — GIE AGSI / ALSI / IIP
https://agsi.gie.eu/
https://alsi.gie.eu/
https://iip.gie.eu/

API registration/key required. AGSI/ALSI publish daily storage/LNG data; GIE also operates an inside-information/UMM platform under REMIT. Check current reuse terms.

## W9O-D05 — NASA Black Marble
https://www.earthdata.nasa.gov/

VNP46/VJ146 daily nighttime-light products are processed within roughly 3–5 hours of acquisition according to NASA Collection 2 documentation.

## W9O-D06 — SEC Form ABS-EE
https://www.sec.gov/submit-filings/technical-specifications

Standardized XML asset-level disclosure for covered registered ABS. Use EDGAR acceptance time as public availability.

## W9O-D07 — CFPB Consumer Complaint Database
https://www.consumerfinance.gov/data-research/consumer-complaints/
https://www.consumerfinance.gov/data-research/consumer-complaints/search/api/v1

Generally updated daily. Complaints publish only after company response/relationship confirmation or 15 days, whichever comes first.

## W9O-D08 — ClinicalTrials.gov API v2
https://clinicaltrials.gov/data-api/api

Store last-update-posted dates and prospectively archive versions. Do not assume an undocumented public history API contract.

## W9O-D09 — CMS Coverage API
https://api.coverage.cms.gov/docs/

Coverage endpoints include NCD/NCA/LCD tracking and history/report structures.

## W9O-D10 — openFDA Device 510(k) / PMA
https://open.fda.gov/apis/device/510k/
https://open.fda.gov/apis/device/pma/

Public approval/clearance records include sponsors/applicants and receipt/decision dates.

## W9O-D11 — DOL / OSHA Open Data
https://data.dol.gov/
https://www.osha.gov/data/

Public enforcement/accident datasets include establishment and event/case fields; some datasets update daily. Preserve publication lag.
