# Wave 4 Source Notes

## U.S. Treasury Buybacks
https://fiscaldata.treasury.gov/datasets/treasury-securities-buybacks/
https://treasurydirect.gov/auctions/announcements-data-results/buy-backs/

## New York Fed Securities Lending
https://www.newyorkfed.org/markets/desk-operations/securities-lending
Daily business-day auction results provide issue-level scarcity information.

## New York Fed Repo / Reverse Repo
https://www.newyorkfed.org/markets/domestic-market-operations/monetary-policy-implementation/repo-reverse-repo-agreements

## DTCC GCF Repo
https://www.dtcc.com/charts/dtcc-gcf-repo-index

## SAM.gov Contract Opportunities
https://open.gsa.gov/api/get-opportunities-public-api/
API key required. Current active opportunity data are updated daily per GSA documentation. Preserve versions locally because the search API emphasizes the latest active version.

## USAspending
https://api.usaspending.gov/
Award data can lag the underlying action and be revised. Record first-public-seen time.

## SEC Ownership and Capital Supply
https://www.sec.gov/search-filings/edgar-application-programming-interfaces
https://www.sec.gov/data-research/sec-markets-data/insider-transactions-data-sets

SEC submissions are disseminated throughout the day. Quarterly flattened ownership datasets are research conveniences, not live feeds.

## FERC eLibrary
https://elibrary.ferc.gov/eLibrary/
Archive first-received/filed/posted metadata and document lineage.

## PHMSA
https://www.phmsa.dot.gov/data-and-statistics/pipeline/distribution-transmission-gathering-lng-and-liquid-accident-and-incident-data
Written incident reports can lag events by up to 30 days.

## CME
